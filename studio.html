Safe Studio

A visual page builder in a single file. Build, debug, ship.

What Is It?

Safe Studio is a visual page builder that runs entirely in your browser. It's one HTML file — download it, double-click, start building. No install, no server, no account. You drag sections onto a canvas, fill them with content blocks, wire up behavior with a safe scripting language, and debug that behavior with a step-by-step time-traveling debugger. The finished page exports as standalone HTML you can host anywhere.

The Canvas

A page is made of sections stacked vertically. Each section has a layout — a hero banner, a three-column feature grid, a pricing table, a footer. Inside each section are blocks: a heading, a paragraph, a button, an image. Drag a layout from the palette on the right, and the blocks fill in with placeholder content you can edit.

75 Tools

The palette has more than text and images. There are chat rooms, video players, comment threads, star ratings, countdown timers, 3D carousels, progress bars, pie charts, data tables, and form inputs. 75 tools across 10 categories. Drop one on a block and the editor shows a live SVG preview of what the tool will look like — a chat tool shows message bubbles, a rating tool shows stars, a chart tool shows bars.

Properties Wizard

Click any block and the properties panel appears. Each tool type has its own settings — a Video tool shows a URL field, a Rating tool shows a star count slider, a Chart tool shows a data editor. Stream-connected tools get smart defaults: the publisher field pre-selects "Current Community" so you don't have to look up user IDs. Color pickers, toggles, dropdowns, and number inputs are generated automatically from the tool's registered properties.

Custom Tools

You can build your own tools from existing ones. Enter the tool editor — it's the same canvas and palette — arrange blocks, write handlers, exit, and your new tool appears in the palette under "My Tools." Drag it onto any page. Each instance keeps its own state, so a "Contact Card" tool used three times on a page holds three separate sets of data.

Mobile-Smart Blocks

Blocks can change shape on phones. Set any block to accordion (tap a header to expand it), dropdown (a button that reveals content), or drawer (slides up from the bottom of the screen). Set a whole section to tabs mode and each block becomes a tab panel. All of this is configured in the properties panel — no code.

SafeScript

SafeScript is how blocks get behavior. Write a handler for onClick, onLoad, or onVisible — the code runs in a sandbox that can read and change elements on the page but can't do anything outside it. No network access, no file access, no eval. You reference elements by name: Section1_$Title.style.color = 'red' changes the title's color. The editor autocompletes element names, stream methods, and tool children as you type.

The Time-Traveling Debugger

Click Step and execution pauses at each line. The locals panel shows every variable and its current value. Hover any variable name in the code to see a tooltip with what it holds right now.

The debugger records every change your code makes in a journal. The actual page stays untouched — the changes are held in an overlay. Scrub backward through the step history and the page rewinds to the state at that exact line. Scrub forward and it replays. At any paused step, fork the timeline to explore a different code path without losing the original one.

When you're done exploring, commit to apply the changes to the real page, or discard to throw them all away. The page returns to its original state as if nothing happened.

The Timeline Tree

Every action in the editor — adding a section, changing a property, running a handler — becomes a node in a tree. Undo moves back one node. Redo moves forward. If you undo to a point and then make a different edit, the tree forks. Both branches stay. A badge on the forking node shows the branch count — click it to switch between them.

The tree renders as a vertical list of colored discs connected by a line. Each disc shows an icon: ✏ for edits, ⚡ for events, ⟨/⟩ for code runs. The active branch is highlighted. You can jump to any node by clicking it, and the page restores to its state at that point.

Projects & Export

A project holds multiple pages. Each page is a tab — Home, About, Pricing. Tools are shared across all pages. Export any page as a standalone HTML file with all content, styles, and behavior baked in. Import pages from JSON. Clone an existing website by pasting its HTML source — Safe Studio extracts the sections, layout, text, images, and color theme mechanically and builds an editable page from it.

What's Next: Collaboration

When Safe Studio connects to a Qbix backend, pages become streams. Two people open the same page and see each other's edits in real time — colored selection outlines show who's working where. Every edit is a message on the stream, so version history comes free. Fork a page to try something different without affecting the original. Invite collaborators with roles (owner, editor, viewer). Comment on individual blocks. The same access control, real-time sync, and notification infrastructure that powers Qbix's social tools powers the page editor.
